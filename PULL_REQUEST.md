## 📝 Описание

Реализована браузерная игра «Футбольная мафия» для игры с друзьями: мультиплеер на
WebSocket-комнатах, полный игровой цикл (ночь → день → голосование → выбывание) и
интеграция с Википедией — роли игроков маскируются под известных футболистов, а их
фотографии и биографии подтягиваются из ru/en Wikipedia API.

## ✨ Что внутри

| Файл | Строк | Назначение |
|---|---|---|
| `server.py` | ~680 | FastAPI + WebSockets: комнаты, раздача ролей (мафия/дон/док/мир), таймер фаз, чат мафии, кэш вики-данных |
| `static/index.html` | ~330 | UI в тёмной «стадионной» теме: лобби, карточки ролей, лента событий, адаптив |
| `static/app.js` | ~310 | Клиент: сокет-соединение, перерисовка состояний, звук/анимации |
| `test_game.py` | ~150 | Интеграционный тест: создание комнаты, подключение 6 игроков, проверка ролей и вики-подсказок |

## 🔧 Технические детали

- **Мультиплеер:** до 12 игроков в комнате, код комнаты генерируется сервером
- **Википедия:** запросы к `ru.wikipedia.org/api/rest_v1` (summary + thumbnail),
  graceful fallback на en-wiki, кэширование, маскировка имён футболистов в подсказках
- **Зависимости:** `fastapi`, `uvicorn`, `httpx`, `websockets`
- **Тесты:** `python test_game.py` — все проверки проходят ✅

## 🚀 Запуск

```bash
pip install fastapi uvicorn httpx websockets
python server.py
# Открыть http://localhost:8000, создать комнату и пригласить друзей по коду
```
